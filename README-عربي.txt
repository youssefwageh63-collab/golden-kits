GOLDEN KITS — نسخة البداية

الموجود:
- متجر عربي متجاوب مع أقسام وبحث وسلة.
- إتمام الطلب بالدفع عند الاستلام.
- لوحة إدارة تجريبية لإضافة المنتجات ومراجعة الطلبات.
- ملف إعداد ربط Supabase.

مهم جداً:
هذه نسخة بداية قابلة للتطوير وليست جاهزة لاستقبال طلبات حقيقية قبل إعداد قاعدة البيانات.
حالياً، إذا تركت config.js فارغاً، تُحفظ الطلبات والمنتجات على نفس المتصفح والجهاز فقط.
حتى تصلك الطلبات من أجهزة العملاء إلى لوحة الإدارة، يجب إنشاء مشروع Supabase وتشغيل supabase-schema.sql ثم وضع رابط المشروع ومفتاح anon في config.js.
لا تضع service_role key في الموقع أبداً.

التشغيل:
افتح index.html في المتصفح لمعاينة المتجر.
افتح admin.html لمعاينة لوحة الإدارة.
للنشر المجاني يمكن استخدام Cloudflare Pages بعد رفع ملفات المشروع إلى GitHub.
